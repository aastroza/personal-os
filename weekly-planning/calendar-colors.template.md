# Calendar Color System (template)

A category color code so your week is legible at a glance. Consult it before creating or editing
any calendar event. Changing a color is low-stakes: the assistant may fix colors automatically as
long as it follows this code. Map the labels to your calendar provider's color IDs.

## Code

| Color | Category | Meaning |
|---|---|---|
| Dark green | LEARN / Study | Courses, reading, research, study, language. Usually a protected morning block. |
| Cyan | BUILD / Practice | Building, prototyping, coding, hands-on practice, portfolio. Often better in the afternoon. |
| Purple | WORK — confirmed | Confirmed interviews, calls, networking meetings; scheduled tests count as confirmed. |
| Blue | WORK — preparation | Interview prep, practicing, profile work, applications, follow-ups, networking planning. |
| Pink | FAMILY (non-negotiable) | Care, pickups, playtime, outings, family routine. |
| Lavender | SPIRITUAL / Emotional | Prayer/meditation, journaling, reflection — including the weekly planning/review block. |
| Sage | BODY / HEALTH | Training, sport, active rest; medical prep protocols (diets, fasting before a test). |
| Yellow | MONEY | Investing review, spend/liquidity/runway, financial decisions (in fixed slots, not compulsive). |
| Orange | ADMIN / Appointments | Bank, medical appointments, errands, bill payments — immovable commitments with third parties. |
| Red | SOCIAL / Cultural (optional) | Casual coffees, hangouts, cultural outings, events — the first thing that moves. |
| Gray | REST / Buffer | Recovery, transitions, weekends, holidays (as all-day markers), unscheduled time. |

## Disambiguation
1. Confirmed vs. prep: agreed-time commitment → Purple; your own preparatory work → Blue.
2. Learn vs. build: summarizing/integrating theory → Learn; building/prototyping → Build.
3. AI automations: default → Build; if tied to job search/networking → Blue; if finance → Yellow.
4. Health: the appointment (immovable, third party) → Orange; the process/prep (diet, exercise) → Sage.
5. Family vs. one-off event: hanging out / family commitment → Pink; ticketed event → Red.
6. Payments/errands: generic → Orange; if tied to banking/investing → Yellow.
7. Reflection/personal planning → Lavender.
8. If an activity spans two categories, create parallel overlapping events and note it.

## Automatic runs vs. confirmed actions
- On an automatic run, colors are only SUGGESTED in the draft, never applied.
- On a confirmed create/edit action, apply the color automatically.
- On a dedicated color-fix task, correct automatically without asking (once this doc is consulted).
