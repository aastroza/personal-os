# Skill: process-backlog

**Trigger:** "process my backlog" / start of week.

**Goal:** turn raw notes in `me/BACKLOG.md` into prioritized, actionable tasks against `me/GOALS.md`.

## Steps
1. Read `me/BACKLOG.md` and `me/GOALS.md`.
2. For each item: clarify into a concrete next action (verb + outcome). Drop duplicates and noise.
3. Assign a **stream** (`ai-native-build`, `job-search`, `investing`, or a life item → Weekly Planning) and a **priority** (P0–P3).
4. Enforce caps: **P0 ≤ 3, P1 ≤ 7.** If over, push the weakest to P2/P3 and say why.
5. Write tasks into the relevant `me/projects/<stream>/TASKS.md`; clear the processed items from BACKLOG.
6. Summarize: what moved where, and the one thing to start now.

**Rules:** don't invent tasks; if an item is unclear, ask one question or mark `→ fill when ready`.
