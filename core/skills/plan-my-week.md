# Skill: plan-my-week

**Trigger:** "plan my week" / Monday.

**Goal:** produce a realistic weekly task contract that respects energy and non-negotiables.

## Steps
1. Ask for this week's **energy throttle (1–5)**. Low → lighter plan with air; high → more deep-work blocks.
2. Read `me/GOALS.md`, each `me/projects/<stream>/TASKS.md`, and `me/GUARDRAILS.md`.
3. Pull the top candidates; select **≤ 7 P1 tasks** for the week (weekly cap). Weight ~80% to the main thing (AI-native) unless goals say otherwise.
4. Protect non-negotiables FIRST (family, faith, exercise, rest) — these are fixed before work.
5. Hand scheduling/calendar to the **Weekly Planning** project (don't duplicate it here); PersonalOS owns the *what/why*, Weekly Planning owns the *when*.
6. Write the result to `me/WEEKLY_PLAN.md` with the energy throttle noted.

**Output:** a short list (≤7) + the single most important outcome of the week.
