# Skill: plan-my-week

**Trigger:** "plan my week" / Monday.

**Goal:** produce a realistic weekly task contract that respects energy and non-negotiables.

## Steps
1. Ask for this week's **energy throttle (1–5)**. Low → lighter plan with air; high → more deep-work blocks.
2. Read `me/GOALS.md`, `me/PROJECT_HQ.md`, each relevant project overview and `TASKS.md`, and `me/GUARDRAILS.md`.
3. Read only relevant decisions, experiment conclusions, and results from `me/memory/` when they can change the plan. Do not load people notes or the entire memory tree by default.
4. Pull the top candidates; select **≤ 7 P1 tasks** for the week (weekly cap). Weight ~80% to the main thing (AI-native) unless goals say otherwise.
5. Protect non-negotiables FIRST (family, faith, exercise, rest) — these are fixed before work.
6. Hand scheduling/calendar to the **Weekly Planning** project (don't duplicate it here); PersonalOS owns the *what/why*, Weekly Planning owns the *when*.
7. Write the result to `me/WEEKLY_PLAN.md` with the energy throttle noted.

**Output:** a short list (≤7) + the single most important outcome of the week.

**Memory boundary:** the weekly plan owns commitments. Do not copy its tasks into memory. If planning exposes stale project context or a superseded decision, propose a targeted memory correction under `core/skills/memory/SKILL.md`.
