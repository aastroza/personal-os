# Skill: skill-review

**Trigger:** weekly heartbeat / "review my skills."

**Goal:** keep the OS lean — prune bloat, dedupe, and sharpen skills so the system improves over time.

## Steps
1. Scan `core/skills/` and any `me/` skill/context files.
2. For each: remove duplicate instructions, cut AI-slop, keep to ~1 page, tighten to signal.
3. Flag anything that produced a bad output this week; propose a concrete fix to that skill.
4. Note skills that are missing (repetitive manual work you did by hand → candidate for a new skill).
5. Summarize changes; apply on approval.

**Rule:** review the input and the output; if the output is good, don't over-engineer the middle. Only go deep where output quality slipped.
